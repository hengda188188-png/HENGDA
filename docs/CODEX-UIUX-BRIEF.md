## 四、硬性規範（違反就是不合格，不是風格偏好）

1. **零外部套件**：不准引入任何 npm 套件、CDN、外部字型、外部圖示庫。整個網頁必須離線可用（這是區網工具）。
2. **顏色一律走 CSS 變數**：`tokens.css` 是唯一色彩來源。**禁止**在 HTML inline style 或 JS 裡寫死色碼。
3. **單一主色 + 中性灰**：禁彩虹漸層、禁多色光暈。強調色只有一個。
4. **禁 emoji 當圖示**：圖示一律 inline SVG（用 `web/js/ui/icons.js`，要新圖示就加進去）。
5. **版面穩定**：任何點擊、篩選、展開都**不得讓框架忽長忽短**。容器要有尺寸約束（固定高／`max-height` + 內捲），內容多就內部捲動。目前 `.gallery-wrap` 高度切篩選前後實測 817.81 → 817.81，**改完必須維持這個特性**。
6. **欄位寬度按內容給**：禁 `width:100%` 沒有 `max-width`。單行輸入 max-width 約 440px，`<select>` 用 `width:auto`。
7. **文案不硬編碼**：所有使用者看得到的字都要走 `web/js/lib/i18n.js` 字典（JS 裡不准出現中文字串常量，`console.*` 的開發日誌除外）。
8. **可及性**：`<img>` 要 alt；只有圖示的按鈕要 `aria-label` 或 `data-i18n-label`；輸入元件要有對應 `<label for>` 或 aria-label；`<html lang>`、viewport、`noindex` 都要保留。
9. **z 軸走集中式發號**：`web/js/ui/overlay.js` 的 `ovTop()`，不准在各處硬寫 z-index。ESC 只關最上層。
10. **RWD**：1440 / 768 / 360 三個寬度都不得有橫向溢出。手機上傳頁在 360px 是實際使用情境（工地／現場），不是加分項。

## 六、真實瀏覽器驗證（不接受「應該沒問題」）

本機有 Chrome：`C:\Program Files\Google\Chrome\Application\chrome.exe`
可用 puppeteer-core 連它做驗證（scratchpad 裝過，或你自己裝在暫存目錄，**不要裝進本專案**）。

改完至少要實測並貼出結果：

1. 三個寬度（1440／768／360）**橫向溢出皆為 0**
2. 切換篩選前後 `.gallery-wrap` 高度差 < 1px（版面穩定）
3. 三個頁面（工作台／手機頁／設定頁）**零 console 錯誤**
4. 主要流程仍可操作：建立專案 → 縮圖就地編輯名稱／描述 → 開放大彈窗 → 開編輯器畫箭頭／文字／螢光筆 → 儲存 → ESC 關閉
5. 淺色與深色（`prefers-color-scheme`）兩種配色都要看過，對比不能糊掉

**注意 puppeteer 兩個坑**（已知，別重踩）：
- SSE 長連線會讓 `waitUntil:'networkidle0'` 永遠不觸發 → 用 `domcontentloaded` + `waitForSelector`
- **背景分頁的 IntersectionObserver 不會觸發**，`page.click` 會協定逾時 → 每次互動前先 `page.bringToFront()`

## 七、我觀察到的待改點（參考，不是命令）

你自己操作過之後可以推翻我的判斷，但**要說明理由**：

1. **縮圖卡片資訊擁擠**：一張卡上有 名稱input／描述input／歸屬＋短碼／狀態標籤＋日期，`.meta` 固定 106px 有點塞。層級可以更清楚。
2. **設定頁很長**：憑證方式切換 → ①②③ 三步 → 工作台密碼 → 影像參數，資訊密度高、缺乏視覺分段與進度感。第一次設定的人容易迷路。
3. **編輯器工具列在窄螢幕換行擠**：`.edit-bar` 有 4 工具 + 5 色票 + 粗細 + 比例 + 4 個動作按鈕。
4. **看圖彈窗側欄固定 320px**：小螢幕會變成上下堆疊，`max-height:46vh`，操作區被壓縮。
5. **手機上傳頁偏陽春**：這是現場最常用的頁面，值得最多注意力（單手可及、大按鈕、上傳狀態一眼看懂）。
6. **沒有深色／淺色手動切換**：目前只跟系統走。工地白天／室內夜間場景可能需要手動。
7. **快捷鍵沒有說明**：`/` 聚焦搜尋、方向鍵切換照片、ESC 關閉，使用者不知道。
8. **空狀態可以更有引導性**：第一次打開什麼都沒有時，指引可以更明確。

**優先順序建議**：手機上傳頁 > 縮圖牆資訊層級 > 設定頁引導 > 其他。理由：手機頁是現場人員在用，錯一步就傳不了圖。
