# PhotoRelay 中央工作台部署與恢復規格

## 目標

讓一台 Windows 設備以原生程式運行中央工作台，手機負責採集圖片，其他多台電腦透過瀏覽器共同查看、編輯、分類、追蹤、上傳 Google Drive 與取得連結。

## 最短啟用流程

1. 將 `PhotoRelay-portable` 複製到新的 Windows 設備。
2. 雙擊 `PhotoRelay.exe`。
3. 在「資料保存與快速恢復」選擇獨立磁碟或 NAS 資料夾。
4. 啟動中央服務。
5. 其他電腦開啟「其他電腦加入」顯示的網址。
6. 在網頁工作台建立或選擇專案，展開 QR 讓手機上傳。

## 資料與程式分離

- 程式：可以隨時重新複製或重新發布。
- 正式資料：`db.json`、圖片、設定與 Google 憑證，全部位於控制程式選定的外置資料位置。
- 新主機恢復：啟動同一份可攜版，重新選擇原資料位置。
- 如果作業環境會被定期還原，資料位置不得位於系統碟的還原範圍內。

## 多設備使用規則

- 同一時間只指定一台中央主機，避免兩個服務各自寫出兩份資料。
- 所有電腦開啟同一個共享網址，現有 SSE 會推送圖片、專案、設備與編輯狀態。
- 多台電腦同時修改同一張圖片時，現有樂觀鎖會阻止舊版本覆蓋新版本。
- 手機端只需要專案 QR/token，不受管理工作台密碼影響。

## 驗收情境

1. 中央主機建立專案，兩支手機各上傳圖片。
2. 兩台電腦同時開啟共享網址，皆能看到新增圖片。
3. A 電腦修改名稱，B 電腦不重整即可看到更新。
4. 圖片確認後上傳 Google Drive，取得圖片與專案資料夾連結。
5. 關閉並重新啟動中央服務，專案、QR token、圖片、標註、設備歸屬與連結仍在。
6. 將可攜版帶到另一台 Windows 設備，指向同一外置資料位置後恢復工作。

## 尚需真實環境驗證

- Windows 防火牆首次允許私人網路連線。
- 真手機在現場 Wi-Fi 掃描 QR。
- 真實 Google 帳號完成授權、圖片上傳和分享權限。
- NAS 路徑斷線後的錯誤提示與重新連線行為。
