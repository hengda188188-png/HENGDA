# 掃碼傳圖工作台（photo-relay）

電腦開網頁 → 出 QR → **手機掃碼傳多張照片** → 電腦端即時出現 → **標註名稱／備註、放大裁切** → 確認後**整批上傳到 Google 雲端硬碟**。

- 位置：`C:\AI_Workspace\products\photo-relay`
- 埠：4901（可在設定頁改）
- 相依套件：**零**（只用 Node 內建與瀏覽器 API），需要 Node 20 以上

---

## 一、怎麼用

### 啟動
桌面上的 **「掃碼傳圖工作台」資料夾 → 啟動捷徑**，或指令：

```powershell
cd C:\AI_Workspace\products\photo-relay
node server.mjs
```

啟動後終端機會印出兩個網址：電腦端 `http://localhost:4901`，以及手機要連的區網網址。

### 傳照片
1. 電腦端左上角「新增專案」，填專案名稱與建立者。
2. 手機（**同一個 Wi-Fi**）掃 QR → **不用輸入名字**，畫面直接顯示這台手機的設備代號（例如 `K7QM`）→ 選照片／拍照。
3. 電腦端左下「今日上傳設備」會出現同一組代號，**在旁邊欄位直接打名字**就完成歸屬指派（例：王小明）。
   歸屬只對「這個專案的今天」有效；**明天或換專案要重新指派**（設計如此，避免沿用昨天的錯誤歸屬）。
4. 照片會在手機端先轉正、壓到設定的最大邊長，再上傳；電腦端縮圖牆**不用重整就會出現**。
5. 縮圖上可以**直接打名稱與描述**（Enter 存、Esc 還原），下面一行顯示歸屬・設備短碼・日期。
6. 點縮圖放大＝**看完整全圖**（不裁切）；按「裁切／旋轉」進編輯器可以拉箭頭、上文字、螢光筆塗重點。
7. 要上雲端的照片標為「已確認」（縮圖右下角打勾鈕，或彈窗內按鈕，或整組／整頁批次）。
8. 按「上傳到 Google 雲端」→ 進度條跑完，會給**雲端資料夾連結**與**可編輯的共用連結**。

### 設備識別怎麼運作（重要）
**瀏覽器拿不到手機的硬體序號** —— iOS 與 Android 都禁止網頁讀取 IMEI／序號這類永久識別碼。
所以本工具的做法是：手機第一次開啟時產生一組固定 UUID 存在該手機的瀏覽器裡，之後每次掃碼都送同一組，
伺服器再換算成好念的 4 碼短碼。效果等同「認得這台手機」，但**清除瀏覽器資料／換瀏覽器／無痕模式會變成新的一台**。

### 圖片標註
編輯器工具列：**裁切／箭頭／文字／螢光筆**，五種顏色、三種粗細，可復原與清除。
標註是**以向量存起來**（不是燒進像素），所以下次再打開編輯器還能繼續改；原圖永遠保留，隨時可「還原成原圖」。

### 多人多台一起用
- **多台電腦同時開工作台**：一台改標註／指派歸屬／新增專案，其他台**不用重整就跟著變**（SSE 推播；斷線重連會自動補齊）。
- **同時改同一張照片**：走樂觀鎖，後送出的人收到 409 並自動載入最新內容，不會後蓋前。
- **跨日、關機、當機重開**：資料存本機 JSON（原子寫入 + 啟動自動備份），**重開後打開網頁就看得到全部過去紀錄**——專案、照片、名稱備註、標註、設備歸屬、實體檔案、連 QR token 都不變（舊 QR 還能用）。
- **回查過去幾天誰傳的**：設備面板可切「今天／全部日期」，全部日期模式會標出每筆是哪一天。

### 工作台密碼（多人區網建議開）
預設**關閉**——沒設密碼時，同一個 Wi-Fi 底下任何人知道網址就能打開工作台。多人共用或公共網路建議設一組：

設定頁 →「工作台存取密碼」→ 輸入新密碼 → 設定密碼。之後：
- 別台電腦第一次開工作台要輸入密碼，**記住 30 天**
- **手機掃 QR 上傳完全不受影響**（現場的人不需要密碼）
- **伺服器重開不會把大家踢出來**
- 改密碼時，其他裝置的登入立刻失效，要重新輸入
- 密碼以 scrypt 雜湊存本機，狀態 API 只回「有沒有啟用」

### 找照片
- **快搜尋**：搜尋框（快捷鍵 `/`）比對名稱／描述／原始檔名／歸屬名稱／設備短碼／機型。
- **篩選列**：狀態（全部／未確認／已確認／已排除）、雲端（已上／未上）、設備，每個都帶即時筆數。
- **依設備分組**：工具列的切換鈕，縮圖牆會依設備分段，每段可整組確認。
- **今日上傳設備面板**：左欄列出今天有哪幾台傳過、各傳幾張，點短碼就只看那台的。
- 條件會寫進網址，可以直接分享或重整不掉。

## 二、Google 雲端硬碟設定

有兩種憑證方式，設定頁最上面可以切換。

| | 一次授權（預設・推薦） | 服務帳戶金鑰（完全免登入） |
|---|---|---|
| 要不要登入 | **只有第一次**，之後永久自動換發權杖 | **完全不用登入** |
| 個人 Gmail 可用？ | ✅ 可以 | ❌ 不行（服務帳戶沒有儲存配額） |
| 需要什麼 | OAuth 用戶端 ID／密鑰 | 服務帳戶金鑰檔（JSON）＋ **共用雲端硬碟**（Google Workspace） |
| 檔案擁有者 | 你 | 服務帳戶（放在共用雲端硬碟裡，團隊共有） |

> **為什麼不能把帳密直接寫進程式**：Google 不接受帳號密碼呼叫 API，一定要 OAuth 或服務帳戶金鑰。
> 想要「完全不登入」就只能走服務帳戶，而服務帳戶**自己沒有儲存空間**，所以只有共用雲端硬碟能收檔案；
> 傳進個人「我的雲端硬碟」會被 Google 以 `storageQuotaExceeded` 擋下（本工具會把這個錯誤翻成白話提示）。

### 方式 A：一次授權（個人 Gmail 就能用）

工具**不會**、也**不能**幫你申請憑證。步驟：

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立一個專案。
2. 「API 和服務 → 程式庫」啟用 **Google Drive API**。
3. 「API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID」，應用程式類型選 **電腦版應用程式**。
4. 複製「用戶端 ID」與「用戶端密鑰」，貼到本工具 **設定頁 → ①**，按「儲存憑證」。
5. 按 **②「連結 Google 帳號」**，在跳出的 Google 頁面同意授權；成功會顯示你的信箱。
6. **③ 目標資料夾**留空即可 —— 工具會自己建一個「PhotoRelay 上傳」資料夾，之後每個專案一個子資料夾。

權限說明：只要求 `drive.file` scope，**本工具只看得到自己建立的檔案**，看不到你雲端其他東西。
用戶端密鑰與 refresh token 只存在本機 `data/secrets.json`（權限 600），**不會回傳到網頁前端**。

> ⚠️ **一個會害你 7 天後被踢出來的坑**：OAuth 同意畫面若停在「測試」狀態，Google 會讓 refresh token 7 天過期。
> 到 Google Cloud → OAuth 同意畫面 → 按「發布應用程式」改成正式即可（`drive.file` 不是敏感範圍，**不需要送審**）。
> 設好之後就真的是「一次授權，之後永不登入」。

### 方式 B：服務帳戶金鑰（完全免登入，需要 Google Workspace）

1. Google Cloud Console → IAM 與管理 → **服務帳戶** → 建立服務帳戶。
2. 進入該服務帳戶 → 「金鑰」→ 新增金鑰 → **JSON** → 下載金鑰檔。
3. 本工具設定頁 → 憑證方式選 **「服務帳戶金鑰」** → 「選擇 JSON 檔」或整份貼上 → 「匯入金鑰檔」。
4. 匯入後畫面會顯示**服務帳戶信箱**（像 `xxx@專案.iam.gserviceaccount.com`）。
5. 到你的**共用雲端硬碟**建一個資料夾 → 把它**分享給那個服務帳戶信箱（編輯者）** → 複製資料夾 ID。
6. 回設定頁「③ 目標資料夾 ID」貼上 → 「檢查並套用」。完成後上傳完全不需要登入。

金鑰檔只存在本機 `data/secrets.json`（權限 600），API 回應**只會吐服務帳戶信箱，不會吐私鑰**。

### 沒驗到的（誠實標注）
1. **真實 Google 帳號上傳未跑過** —— 需要你的 OAuth 憑證才能測。目前只驗到「未設定／未授權時會明確擋下並導向設定頁」。憑證填好後請先用 2–3 張照片試跑一次。
   **共用連結（可編輯）** 同理：程式會對專案資料夾建立 `anyone/writer` 權限並回傳連結，但沒有用真帳號跑過。
2. **真手機掃真 QR** —— QR 內容與網址已驗證正確、手機頁在 360px 真瀏覽器測過，但沒有用實體手機相機掃過。
3. **HEIC 實機** —— iPhone 若給 HEIC，程式會退回原檔直傳並標記無法預覽；此路徑未用真 HEIC 檔測過。
4. **服務帳戶模式沒有對真的共用雲端硬碟傳過** —— 需要 Google Workspace 帳號。已驗到：金鑰檔驗證、RS256 簽章可被公鑰驗證、模式切換、未設目標資料夾會明確擋下、配額錯誤會翻成白話。
5. **基地官方閘門未跑** —— 這台電腦只有 claude-sync 骨架，沒有 `tools/ui-constraints/check.mjs`、`tools/web-standard-check.mjs`、`tools/feature-map/fm.mjs`。本專案自帶 `test/gate.mjs` 頂替（可及性／emoji／內聯色碼／容器約束／i18n 硬編碼／死代碼）。**回到主基地請補跑官方三道閘門**，`feature-map.json` 已經備好。

## 四、資安做法（對應憲法第 23 條）

| 面向 | 作法 |
|---|---|
| 上傳授權 | 手機端每支寫入 API 都要專案 token，定時比較；token 可隨時重產使舊 QR 失效 |
| 檔案型別 | **magic bytes 判定**，不信任 Content-Type／副檔名；偽裝的 exe 直接 400 且不落地 |
| 檔案大小 | 串流中途超限即中止並刪暫存檔，不會寫滿磁碟 |
| 路徑穿越 | 落地檔名由伺服器決定（`<photoId>.<ext>`），使用者檔名只當資料；靜態檔限制在 web/ 內 |
| 速率限制 | 同 IP 每分鐘寫入上限（預設 120，可調），超過回 429 |
| 密鑰 | 只存本機 `data/secrets.json`（600），API 回應一律遮罩 |
| 索引 | 全站 `noindex`，這是內部工具不該被搜尋到 |
| 設備識別 | 只存隨機 UUID 與裝置描述（UA／螢幕／時區），不做跨站追蹤；歸屬綁當天當專案 |
| 共用連結 | 「知道連結的人可編輯」是公開可寫，UI 旁邊明白標示風險，不預設開啟以外的分享 |
| 併發 | 多裝置同改一張照片走樂觀鎖，衝突回 409 附最新值，不做 last-write-wins |

## 六、常見狀況

| 狀況 | 處理 |
|---|---|
| 手機掃了打不開 | 確認手機跟電腦同一個 Wi-Fi；左欄「電腦網址」下拉換一個 IP（VPN／虛擬網卡會被自動排後面） |
| 埠被占用 | `set PHOTO_RELAY_PORT=4902` 後重新啟動，或到設定頁改埠（改完要重啟） |
| 照片傳不上去 | 手機端每張都有獨立錯誤訊息與「重試」；檢查是否超過單檔上限或型別不支援 |
| 想換 Google 帳號 | 設定頁「解除連結」→ 重新授權 |
| 資料在哪 | `data/`，`db.json` 每次啟動會自動備份成 `db.backup.json` |
